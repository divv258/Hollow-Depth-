# Hollow Depth

A Hollow Knight-inspired metroidvania platformer built in HTML5 Canvas 2D.

## About
- 3 Acts: Forgotten Cavern, Queen's Glass Sanctuary, Great Bell Vein
- Custom physics engine (gravity, tile collision, wall-jump, dash)
- Player mechanics: slash combo, pogo, focus/heal, dash, wall-jump
- 2 enemy types + unique boss per act
- Procedurally generated maps
- Web Audio API for sound

## How to Play
Open index.html in any modern browser.

## Tech Stack
- Vanilla HTML5 + JavaScript (no libraries)
- Canvas 2D API for rendering
- Web Audio API for sound
- CrazyGames SDK v3

## Porting
This game is being ported to Godot 4.
